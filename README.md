# AGRIVIVE — India’s Farming Wisdom, Reimagined

India’s farming wisdom, reimagined for a living future. Explore 28 state rooted stories, farming traditions and thoughtful modern agricultural concepts designed with care for land, water and nature. Select a state on the map to read its story and explore the 3D assembly. The 28 A3 technical sheets are linked from each study.

The 3D concepts are for visual exploration and are not fabrication CAD or validated agricultural equipment. Dimensions and unspecified structural assumptions are preliminary.

All model and map content is embedded in `index.html`. A3 technical sheets are in `technical-sheets/`.
